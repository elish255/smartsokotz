SMART SOKO — SPLASHPAY PAYMENT SETUP

Vercel > Project > Settings > Environment Variables:
- SUPABASE_URL (or VITE_SUPABASE_URL) = your Supabase project URL
- SUPABASE_PUBLISHABLE_KEY (or VITE_SUPABASE_PUBLISHABLE_KEY) = your Supabase publishable/anon key
- SUPABASE_SECRET_KEY or SUPABASE_SERVICE_ROLE_KEY = Supabase secret/service-role key (server-side only; NEVER use VITE_ prefix)
- SPLASHPAY_API_KEY = SplashPay API key (server-side)
- SPLASHPAY_API_SECRET = SplashPay API secret (server-side)

Payment initiation uses POST /api/v1/payments/mobile-money and status checks use POST /api/v1/payments/check-status. No webhook is used. New payment references use INV-... . After changing environment variables, redeploy the project. Never paste secret keys into frontend code or public GitHub files.
